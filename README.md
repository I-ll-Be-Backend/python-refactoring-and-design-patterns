Code from the [I'll Be Backend](https://www.youtube.com/@illbebackend) videos: messy Python code gets better, one small, safe refactoring at a time. Every lesson has a video, an [interactive version](https://illbebackend.dev) you can step through, and a folder here with the code after every step.

## How to use it

- Open a lesson folder and read its README, then the step folders in order.
- `sh check.sh` compiles every step in Docker with `python:3.12-slim`, the same check every lesson passed before its video went out.
- Found a bug in a lesson? Open an issue.
